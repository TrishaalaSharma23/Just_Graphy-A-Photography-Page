# Just_Graphy-A-Photography-Page

⚙️ Run Locally
1) git clone <repository-url>
2) cd JUST_GRAPHY
3) Open MiniProject.html in your browser.

JUST GRAPHY is a responsive photography portfolio landing page built using HTML5 and CSS3, featuring a modern sidebar navigation system and visually engaging UI design.

Speciality of the Project:
1) Implemented an interactive sidebar menu using pure CSS without JavaScript.
2) Designed a modern photography-inspired UI with smooth layout structuring and icon integration.
3) Optimized lightweight static frontend architecture for fast performance and clean user experience.

Tech Stack:
1) HTML5
2) CSS3
3) Font Awesome
4) Google Fonts

Features:
1) Responsive layout
2) Sidebar navigation
3) Social media integration
4) Modern UI/UX design
5) Pure CSS interactions
